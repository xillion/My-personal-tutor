# 05. Тестирование и Definition of Done

## Пирамида

| Уровень | Инструмент | Что покрывает | Где |
|---------|-----------|---------------|-----|
| Unit Rust | `cargo test`, `insta` (снапшоты), `proptest` | парсер, токенизатор, валидатор, check_answer, SRS, $Q, импорт | `crates/*/tests`, `#[cfg(test)]` |
| Golden | `insta` | `lesson.md` → AST JSON для эталонных курсов | `crates/mpt-core/tests/golden/` |
| Storage | `rusqlite` in-memory | миграции, репозитории, изоляция профилей | `crates/mpt-storage/tests` |
| Fuzz (необяз.) | `cargo-fuzz` | парсер разметки, распаковка zip | `fuzz/` |
| Unit TS | Vitest | state-классы, бинарный поиск таймлайна, нормализация штрихов | `src/**/*.test.ts` |
| Компоненты | Vitest + @testing-library/svelte + `mockIPC` из `@tauri-apps/api/mocks` | рендер урока, popover, QuizRunner | `src/**/*.test.ts` |
| E2E | WebdriverIO + `tauri-driver` | сквозные сценарии на собранном приложении | `tests/e2e/` |
| Ручной QA | чек-лист | аудио, TTS, планшет на реальных ОС | `docs/qa/manual-checklist.md` |

`tauri-driver` работает на Windows и Linux; macOS проверяется вручную по чек-листу.

## Обязательные тесты по областям

- **Импорт:** валидный пакет; битый JSON; нет обязательного файла; несовпадение sha256;
  zip-slip (`../evil`); абсолютный путь; симлинк; zip-bomb (коэффициент сжатия);
  неподдерживаемый `format_version`; обновление с удалённым и переименованным элементом —
  прогресс сохранён.
- **Токенизатор:** апострофы (`don't`, `I'm`, `rock’n’roll`), дефисы, числа (`3.14`, `1,000`),
  кавычки «» и "", кириллица + латиница в одном предложении, эмодзи; инвариант: склейка
  токенов = исходный текст.
- **Выравнивание:** выход выравнивателя с другой токенизацией сопоставляется ≥ 95%.
- **check_answer:** табличные тесты на каждый тип и правило нормализации.
- **SRS:** симуляция 30 дней с фиктивными часами: интервалы растут при верных ответах и падают
  при ошибке; `rating_from_outcome` по таблице ADR-08.
- **Караоке:** бинарный поиск на границах, паузах между словами, перемотке назад.
- **Безопасность игр (Фаза 7):** из iframe недоступны parent DOM, IPC, сеть.

## Сквозной сценарий MVP (E2E-01)

1. Первый запуск → создание профиля «Тест».
2. Родительский шлюз → импорт `sample-en.mpt` и `sample-math.mpt`.
3. Открыть урок `knight` → проиграть аудио 3 с → активный токен меняется.
4. Клик по `knight` → карточка с переводом и IPA → «Изучать».
5. Повторить для 4 слов и 1 термина из `sample-math`.
6. Пройти квиз урока (≥ 1 вопрос каждого типа MVP).
7. Сессия повторения → ответить на все карточки.
8. Перезапустить приложение → словарь содержит 5 элементов, прогресс урока и `review_log` на месте.
9. Экспорт прогресса → удалить профиль → импорт → состояние совпадает.

## Definition of Done (для каждой задачи)

- [ ] Критерии приёмки задачи из `04_ROADMAP.md` выполнены и проверены.
- [ ] `just check` зелёный: `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`,
      `pnpm lint`, `pnpm check` (svelte-check), `pnpm test`, актуальность `just gen`.
- [ ] Новые публичные функции ядра покрыты тестами; багфикс — тест, который падал до фикса.
- [ ] Контракты (`mpt-core::model`, IPC, миграции, формат курса) изменены только с ведома
      `architect`, документация обновлена в том же PR.
- [ ] Ревью агентом `code-reviewer` проведено, замечания уровня `blocker`/`major` закрыты.
- [ ] Строки UI — через i18n; нет хардкода текста в компонентах.
- [ ] Статус задачи в `04_ROADMAP.md` обновлён, запись в `CHANGELOG.md`.
