---
description: Независимое ревью текущих изменений агентом code-reviewer
argument-hint: "[диапазон git, по умолчанию main...HEAD] [T-xxx]"
---

Вызови агента `code-reviewer` для изменений **$ARGUMENTS** (если диапазон не указан — `main...HEAD`,
плюс незакоммиченные изменения из `git diff`). Если указан ID задачи, передай её приёмку из
`docs/04_ROADMAP.md`. Покажи человеку вердикт и замечания как есть, ничего не исправляй без запроса.
